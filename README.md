# 롤FM · rollFM

**[▶ 게임 바로 하기](https://gaolgaol.github.io/roll-fm-play/)**

LoL 프로팀의 밴픽과 AI 경기를 즐기는 무료 팬 메이드 시뮬레이션 게임입니다. 웹 브라우저에서 로그인이나 설치 없이 플레이할 수 있습니다.

> **본 게임은 수익을 창출하지 않는 무료 팬 메이드 게임이며, 현재 개발 중입니다.**

>
> 본 프로젝트는 Riot Games 또는 각 LoL 이스포츠 구단이 제작하거나 공식 승인한 게임이 아닙니다.

## 현재 개발 상태

현재 공개 버전은 **v0.43**이며, 기본 게임 규칙은 **LoL 패치 26.20**을 기준으로 개발하고 있습니다. 프로젝트 버전과 LoL 패치 번호는 서로 다릅니다.

프로 밴픽, 선수 정보, 3D 경기 관전 등을 제공하는 개발 중인 버전입니다. 일부 챔피언 스킬·아이템·룬·세부 판정은 미완성이고, 효과 연출과 경기 AI도 계속 보완하고 있습니다. 실제 LoL의 모든 규칙·연출을 완전히 재현한 버전은 아닙니다.

선수 능력치와 숙련도에는 공개 경기 기록에 따른 추정과 게임용 평가가 포함됩니다. 근거가 부족한 항목은 화면에 별도로 표시하며, 실제 선수의 심리·성격이나 미래 성장 가능성을 객관적으로 측정한 값이 아닙니다. 장기 육성·훈련·이적 등 FM식 전체 운영 시스템도 완성된 상태는 아닙니다.

## 게임 방법

### 1. 빠르게 시작하기

1. **[게임 링크](https://gaolgaol.github.io/roll-fm-play/)**를 엽니다.
2. 기본 설정인 **T1 vs GEN**으로 플레이하려면 **밴픽 시작 →**를 누릅니다.
3. 내 차례에 챔피언을 선택해 밴과 픽을 진행합니다. 기본 시간 무제한 모드에서는 선택하면 바로 반영됩니다.
4. 상대 차례에는 AI가 밴픽을 진행합니다.
5. 총 **20단계** 밴픽이 끝나면 챔피언을 드래그하거나 드롭다운에서 골라 포지션을 조정하고, **최종 배치 확정**을 누릅니다.
6. **▶ 경기 중계 보기**를 누른 뒤 경기 준비 화면에서 소환사 주문·룬을 설정하고 **경기 시작 →**를 누르면 AI 경기를 관전할 수 있습니다.

챔피언을 직접 움직이는 방식이 아니라, 밴픽과 선수 배치를 정하고 AI의 경기를 지켜보는 방식입니다.

### 2. 팀과 규칙 바꾸기

첫 화면의 **팀·모드 바꾸기**에서 다음을 설정할 수 있습니다.

| 설정 | 내용 |
| --- | --- |
| 내 팀·상대 팀 | 리그와 프로팀 선택 |
| 밴픽 진영 | 블루 선픽 / 레드 후픽 |
| 시리즈 | 단판 / BO3 / BO5 |
| 조작 방식 | AI 상대 / 양 팀 수동 조작 |
| 밴픽 시간 | 시간 무제한 / 실전 시간 제한 |
| 피어리스 | BO3·BO5에서 이전 세트에 사용한 챔피언의 재사용 제한 |

**실전 시간 제한**에서는 챔피언을 선택한 뒤 **밴 확정 / 픽 확정**을 눌러야 합니다. 밴·픽은 30초, 최종 배치는 60초 제한입니다. 피어리스의 **이전 픽의 밴도 제한** 옵션도 별도로 선택할 수 있습니다.

양 팀 수동 조작은 같은 화면에서 양쪽 밴픽을 직접 정하는 연습 모드입니다. 온라인 대전 기능을 뜻하지 않습니다.

### 3. 경기 관전과 저장

- 밴픽 없이 먼저 보고 싶다면 첫 화면의 **▶ 3D 중계 체험**을 누르세요.
- 중계 화면에서는 **재생·일시정지, 배속, 자동 관전, 전체 맵, 카메라 확대·축소**를 사용할 수 있습니다.
- 화면이 무거우면 **화질 → 가벼움**을 선택하거나 배속을 낮춰 주세요.
- **정보 시점**에서 관전자 전체 / 블루팀 지식 / 레드팀 지식을 선택할 수 있습니다.
- 밴픽 중에는 **저장·연습 도구 → 현재 밴픽 저장**을, 중계에서는 **경기 저장 / 경기 불러오기**를 사용하세요.
- 저장은 사용 중인 브라우저에 보관됩니다. 다른 기기·브라우저로 자동 동기화되지 않으며, 브라우저 사이트 데이터를 삭제하면 저장 내용이 사라질 수 있습니다.

### 4. 선수 정보와 미리보기

- **선수 능력치 · 숙련도 · 시그니처**를 열면 기본 평가, 장기 챔피언 숙련도, 최근 준비도, 사용 기록과 근거 부족 여부를 확인할 수 있습니다.
- **크기·기본 동작 비교**에서 모델과 기본 애니메이션을 살펴볼 수 있습니다.
- **스킬 이펙트 미리보기 / 전체 챔피언 이펙트**에서 스킬 연출을 볼 수 있습니다. 연출이 있다는 것만으로 해당 스킬의 모든 게임 판정이 완성됐다는 의미는 아닙니다.
